# 📊 Excel Sales Dashboard

## 📌 Project Overview
This project presents a sales dashboard built using Microsoft Excel to analyze sales performance across products, categories, months, and regions. The dashboard transforms sales data into visual insights that help users understand business performance and identify sales trends.

## 🎯 Objectives
- Analyze overall sales performance.
- Compare sales across product categories and individual products.
- Understand monthly sales trends.
- Evaluate sales distribution across regions.
- Present key business insights through visualizations.

## 🛠️ Tools & Technologies
- Microsoft Excel
- PivotTables and Charts
- Data Analysis and Visualization

## 📈 Key Insights
- **Total Sales:** 1,552,500
- **Top Category:** Electronics — 1,125,000
- **Top-Selling Product:** Laptop — 585,000
- **Highest-Sales Month:** January — 925,500
- **Top Region:** West — 514,500

*Note: The figures reflect the dataset analyzed in this project. The currency is not specified in the source data.*

## 📂 Project Files
- `Dashboard.xlsx` — Excel workbook containing the sales dashboard and analysis.
- `Summary.pdf` — Summary report of the project findings.

## 🚀 How to Use
1. Download `Dashboard.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Explore the dashboard charts and sales summaries.
4. Review `Summary.pdf` for a concise overview of the findings.

## 💡 Skills Demonstrated
Data analysis, dashboard creation, chart design, business reporting, and interpretation of sales trends.

## 🏁 Conclusion
This project demonstrates how Excel can be used to organize sales data, visualize performance, and communicate useful business insights through a dashboard.

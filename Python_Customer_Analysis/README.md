# 🐍 E-Commerce Customer Behavior Analysis

## 📌 Project Overview
This project analyzes e-commerce customer behavior using Python. It explores customer demographics, transaction amounts, sales trends, purchasing patterns, customer segments, and payment preferences through data analysis and visualization.

## 🎯 Objectives
- Explore customer demographics and transaction amounts.
- Analyze monthly e-commerce sales.
- Understand customer segments and purchasing behavior.
- Perform Recency, Frequency, and Monetary (RFM) analysis.
- Examine relationships between customer age, spending, and purchase frequency.
- Analyze cumulative revenue and customer contribution.
- Explore product category sales and payment method usage.

## 🛠️ Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Analysis & Visualizations
The notebook includes visualizations covering:
- Customer age and transaction amount distributions
- Monthly e-commerce sales
- Customer segmentation
- RFM score heatmap
- Correlation between customer age, spending, and purchase frequency
- Cumulative revenue and Pareto analysis
- Sales by product category
- Payment method usage

## 📂 Project Files
- `E_Commerce_Customer_Behavior_Analysis.ipynb` — Notebook containing the analysis, code, and visualizations.
- `ecommerce_customer_behavior_dataset.csv` — Dataset used for the analysis.

## 🚀 How to Run
1. Download or clone the repository.
2. Ensure the notebook and CSV dataset are in the same folder.
3. Install the required Python libraries.
4. Open the notebook in Jupyter Notebook or Google Colab.
5. Run the cells in order to reproduce the analysis.

Install the main libraries with:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Data cleaning, exploratory data analysis, customer segmentation, RFM analysis, correlation analysis, data visualization, and business insight generation.
